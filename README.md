# Industrial Hackathon 2026
Entry point for participants working on Equinor industrial data hackathon 2026.

## Challenges

### [Ask Volve](ask-volve/README.md)

Build a conversational assistant for public Volve production data and technical reports.

### [Hywind Tampen Wind Forecast](hywind-tampen-wind-forecast/README.md)

Forecast turbine wind conditions and warn operators about wind drops using participant-provided data.

Each use-case folder contains a problem description, suggested objectives, evaluation criteria, and a
`data/` directory with dataset-specific instructions.
